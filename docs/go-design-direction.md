## 2. 방향 — "종이 지도의 확신, 앱의 반응"

레퍼런스는 **밝은 야외용 계기판**이다. 장식 0, 대비 최대, 지금 할 일 하나가 화면을 지배한다.

1. **밝다.** 흰 바탕 + 잉크색이 기본. 다크는 "밤" 토글로만(호텔에서 마감 3문답 쓸 때).
2. **하나만 크다.** 카드의 주인공은 1개 — 시간 상태와 장소명. 나머지는 그 아래.
3. **누르면 즉시 안다.** 모든 탭이 누르는 순간 반응하고, 완료는 눈에 보이게 쌓인다.

## 3. 구조 (v1 에서 바뀌는 것)

**신설 2개**

- **시간 인지 스트립** — 현재 카드 예정 시각과 지금을 비교해 "38분 여유 / 12분 늦음"을 한 줄로.
  여행 중 가장 자주 묻는 질문인데 지금은 사람이 암산한다.
- **사람 필터** — 전체·아빠·언니·동생 탭. `all`·`both` 미션은 항상 표시.

**고친다**: 라이트 퍼스트 · Dynamic Type 허용 · `:active` 즉시 피드백 · translucent 헤더 ·
체크 시 진행 카운트 · 스냅 이동 인터럽트 가능.

**안 한다**(YAGNI): 지도 임베드(네이버 앱이 낫다) · 사진 업로드 · 실시간 동기화 · 로그인.
